# Landing Page Project

## Overview

This project is part of the curriculum from The Odin Project.
The goal was to recreate a full web page from a provided design using only **HTML and CSS**.

The project focuses on translating a static design into a functional web page while respecting layout, typography, and visual hierarchy.

Rather than aiming for pixel-perfect accuracy, the objective was to understand how to structure a webpage and position elements properly.
---

## Objectives

The main goals of this project were to:

- Practice structuring a webpage with **semantic HTML**
- Apply **CSS styling and layout techniques**
- Use **Flexbox** to organize content and sections
- Recreate a design from an image reference
- Improve problem-solving skills while building from scratch

---

## Features

- Hero section with headline and call-to-action
- Information section with multiple content blocks
- Quote/testimonial section
- Call-to-action section
- Footer

The page is designed for **desktop view**, focusing on layout and structure rather than responsiveness.

---

## Technologies Used

- HTML5
- CSS3
- Flexbox
- Git & GitHub

---

## What I Learned

During this project I improved my understanding of:

- Breaking a design into logical **sections**
- Structuring content before styling
- Using **Flexbox for layout**
- Managing spacing and alignment
- Organizing a project workflow using **Git commits**

This project helped reinforce fundamental front-end development skills.
